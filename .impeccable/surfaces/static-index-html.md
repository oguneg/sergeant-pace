# Surface brief: the whole Sergeant Pace app (static/index.html)

Mode: Experience (the artifact leads; this app is screen-recorded as a showcase video, desktop 16:9 first, mobile must still work).

Audience and job: hackathon judges watching a video, then beginner runners. The memory to leave: the agent visibly deciding. Must not be cartoonish or cutesy; must read at a glance.

Constraints: one recruit, Flask backend, no image generation, code-led build, fonts self-hosted in static/fonts (Big Shoulders Stencil Display, Archivo, Courier Prime).

## Direction contract

THESIS: The app is the recruit's individual counseling file. Every run ends in a counseling session the agent conducts on paper, in public: facts typed in, assessment boxes inked, a plan of action decided and stamped, the old plan struck through and the new one written beneath. It refuses the chat bubble with an avatar and the fitness-app card stack.

OWN-WORLD: Olive-drab desk as the committed ground. Cool copy-paper forms with 1px black rules and ruled cells. Blue-black typed entries in a typewriter face, stencil display for headings and stamps, narrow grotesque caps for form captions. Red stamp ink means failed or stop, blue stamp ink means approved, a hazard-striped amber plate marks a tripped safety rule. A drawn chevron insignia, no emoji. Paper casts offset soft shadows on the desk. Recognizable with all copy removed.

STORY: The recruit sees what the sergeant decided about the last run and why, believes the safety limits are real rules because each stamp cites one, and does the next thing: acknowledge orders and run.

FIRST VIEWPORT: Olive desk. One wide form sheet fills the frame: a header band with the chevron insignia, SERGEANT PACE, INDIVIDUAL TRAINING FILE and a form number. Below it the first question in stencil at display scale, CAN YOU RUN RIGHT NOW?, with two large checkbox answer cells. Under them, ruled lines headed RECORD SO FAR wait for typed entries. The only action is the stamped box that confirms the answer.

FORM: Developmental counseling record (Facts, Assessment, Plan of Action, Counselor's Remarks), position 1 on my ordered list, chosen by the user as the pick over the dealt assignment (split-flap departure board). Seed key 70cc2310.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
